# VPN 접속 가이드

> 교육용 더미 데이터입니다.

## 접속 방법

사내 VPN 클라이언트를 실행하고 사번과 사내 계정 비밀번호로 로그인합니다.
VPN은 사내 계정과 연동되므로 **계정이 잠겨 있으면 VPN도 접속되지 않습니다.**
VPN 접속이 안 될 때는 먼저 계정 잠금 여부를 확인하세요.

## 인증서 오류 해결

"인증서가 유효하지 않습니다" 또는 "인증서 만료" 오류가 나면 아래 순서로 재발급합니다.

1. VPN 클라이언트를 완전히 종료합니다.
2. 사내 포털 → IT 서비스 → "VPN 인증서 재발급" 메뉴에 들어갑니다.
3. 재발급 버튼을 누르고 내려받은 인증서 파일을 실행해 설치합니다.
4. PC를 재시작한 뒤 VPN 클라이언트로 다시 접속합니다.

인증서 유효기간은 발급일로부터 1년입니다. 재발급은 하루 3회까지 가능합니다.

## 자주 나오는 증상

- 접속 중 계속 끊김: 무선 공유기 절전 모드를 끄고 유선으로 다시 시도합니다.
- "사용자 인증 실패": 비밀번호 만료 또는 계정 잠금일 가능성이 높습니다. 계정 상태를 확인하세요.

## 문의

위 절차로 해결되지 않으면 IT 헬프데스크 채널(사내 메신저 #it-helpdesk)로 문의합니다.
