# SW 설치·라이선스 정책

> 교육용 더미 데이터입니다.

## 설치 원칙

- 업무용 PC에는 **사전 승인된 SW만** 설치할 수 있습니다.
- 승인 목록에 있는 SW는 사내 포털 → IT 서비스 → "SW 센터"에서 직접 설치합니다.
- 승인 목록에 없는 외부 프로그램은 설치 전에 반드시 승인을 받아야 합니다.

## 외부 프로그램 설치 승인 절차

1. 사내 포털 → IT 서비스 → "SW 설치 요청" 양식을 작성합니다. (프로그램명, 버전, 업무 사용 목적)
2. 소속 팀장이 1차 승인합니다.
3. 보안팀이 보안 검토를 진행합니다. 보통 영업일 기준 3일이 걸립니다.
4. 승인되면 SW 센터에 해당 프로그램이 표시되고 직접 설치할 수 있습니다.

승인 없이 설치한 프로그램은 보안 점검에서 자동 삭제될 수 있습니다.

## 라이선스

- 유료 SW 라이선스는 자산(PC) 단위로 배정됩니다.
- 라이선스 만료 30일 전에 갱신 안내 메일이 발송됩니다.
- 본인 PC의 라이선스 현황은 헬프데스크 Agent 또는 SW 센터에서 확인할 수 있습니다.
- 퇴사·PC 교체 시 라이선스는 회수 후 재배정됩니다.
